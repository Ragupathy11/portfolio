A web application built using HTML, CSS, JavaScript, and Bootstrap for efficient task management. Users can add new tasks, edit existing ones, delete them, and mark them as complete. Weather Forecast App:

A JavaScript-based app that fetches real-time weather data using an external API. It displays temperature, humidity, and weather conditions in a visually appealing format. Weather icons and colors indicate different conditions like sunny, rainy, or cloudy. The app also allows users to search for different city forecasts. Great for learning API integration and UI design.

A Java and MySQL project for conducting online quizzes. It dynamically generates questions from a database, ensuring variety.
